# Sorties d’expériences

Ce dossier reçoit notamment les runs MAE : configurations, métriques,
caractéristiques et checkpoints. Les autres pipelines écrivent dans leurs
propres dossiers `artifacts/` ou dans les sorties Kaggle.

Les sorties complètes restent locales. Les résultats agrégés sélectionnés
pour la présentation se trouvent dans [`docs/results/`](../docs/results/README.md).
